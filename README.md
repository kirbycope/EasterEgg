# EasterEgg
Easter Eggs for Minecraft Bedrock.

## Installation
1. Download the [mcaddon](https://github.com/kirbycope/EasterEgg/releases/latest/download/EasterEgg.mcaddon)
1. Double-click the mcaddon file
1. Load the Resource and Behaviour packs for your world/save

## Requirements
Minecraft Bedrock 1.26.0 or newer, with no experiments.
